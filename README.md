Full documentation: **[indentier.github.io](https://indentier.github.io)**

## Install

```sh
npm i -D indentier @indentier/plugin-css
```

## Setup

```jsonc
// .indentierrc.json
{
  "plugins": ["@indentier/plugin-css"]
}
```
